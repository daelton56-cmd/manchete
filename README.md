# Manchete

Cartas estilo FUT, agenda, presença, sorteio de times e súmula do vôlei da galera.

Abrir no iPhone: https://daelton56-cmd.github.io/manchete/ (Safari, Compartilhar, Adicionar à Tela de Início).

Os dados ficam salvos no próprio celular. Use **Salvar backup** no botão de ajuda de vez em quando.
